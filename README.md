# ReceiptSafe Kenya

## Receipt Storage and Management System

ReceiptSafe Kenya is a web-based receipt management system designed to help users store, organize, search, and manage receipt records digitally.

The system aims to reduce misplaced receipts, duplicate records, delays in retrieving information, and difficulties in tracking receipt transactions.

## Features

- User registration and login
- Dashboard with receipt statistics
- Add and view receipts
- Edit receipt records
- Search receipts by receipt number, customer, business, or category
- View recent receipts and activity
- Reports and receipt summaries
- User-specific receipt access

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP for local development
- InfinityFree for online hosting
- Git and GitHub for version control

## Installation and Setup

1. Install XAMPP and start Apache and MySQL.
2. Clone or download this repository into your XAMPP `htdocs` directory.
3. Create a MySQL database for the project.
4. Import your database schema or a clean sample database.
5. Configure your local database connection using your own private configuration.
6. Open the project through your local server in a web browser.

**Security note:** Database credentials and real customer data should never be committed to the public repository.

## Project Purpose

This project demonstrates the development of a practical web-based system for improving digital receipt storage, retrieval, and management.
